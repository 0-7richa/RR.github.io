# Dr. Richa Ranjan — Free Academic Website

A responsive, static website for an academic portfolio, research showcase, and personal profile.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive design and visual styling
- `script.js` — mobile navigation and current year

## Before publishing
1. Open `index.html` in a text editor.
2. Replace `YOUR.EMAIL@EXAMPLE.COM` with the professional email address you want to publish.
3. Add verified Google Scholar, ORCID, LinkedIn, and other profile URLs.
4. Add verified degrees, institutions, dates, complete publication list, author order, and academic achievements.
5. Review all research/project descriptions for accuracy.
6. Save the changes.

The publication already listed links to the DOI `https://doi.org/10.1016/j.hazadv.2026.101015`. Verify author details and the final bibliographic record before publishing.

## Preview locally
Double-click `index.html` to open it in a browser. An internet connection is needed for the optional Google Fonts; the website itself is static and does not require a backend.

## Publish for free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com/.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io` (replace with your username).
3. Upload `index.html`, `styles.css`, and `script.js` to the repository's root folder.
4. Open the repository's **Settings → Pages**.
5. Under build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
6. Wait for the deployment to finish. Your site will be available at `https://YOUR-GITHUB-USERNAME.github.io/`.

GitHub Pages hosting is free for public repositories. A custom domain is optional and usually costs extra.

## Important
This is a static website. The contact email link opens the visitor's email application; there is no server-side contact form. Do not publish private information. Keep institutional affiliations, credentials, awards, and publication metadata accurate.
